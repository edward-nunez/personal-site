# Patterns and Practices

This directory contains standardized patterns, conventions, and best practices for the Personal Site v2 project.

## Available Patterns

### [Microservice Naming Convention](./MICROSERVICE_NAMING.md)

Standardized naming pattern for all microservices in the monorepo:
- **kebab-case** for directories, URLs, and file names
- **PascalCase** for documentation and prose
- **camelCase** for code variables and object keys

## Purpose

These documents serve as:
- **Reference guides** for consistent implementation
- **Onboarding materials** for new contributors
- **Decision records** documenting architectural choices
